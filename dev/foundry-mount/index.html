Wave 6 — Foundry mount prototype

This page owns a bare PIXI.Application that this board code did not create — a stand-in for Foundry's own ambient one. A "primary" container plays the part of whatever scene-level container Foundry nests its content under: it sits at 0.5× scale with an offset, unrelated to the board. BoardContainer mounts inside it via mountBoardView (see src/board/index.ts, docs/pixi-board.md), driven from battle-state.json — not the app's own BoardApp/ createBoardView.
